# Data Source

The dataset used in this project is the **Online Retail Dataset**, publicly available on Kaggle.

- Platform: Kaggle  
- Dataset name: *Online Retail Dataset*  
- Dataset URL: https://www.kaggle.com/datasets/hellbuoy/online-retail-dataset  
- Original source: UCI Machine Learning Repository  

The dataset contains transactional data from a UK-based online retailer, covering the period from December 2010 to December 2011.

The data was used strictly for **educational and portfolio purposes**.
